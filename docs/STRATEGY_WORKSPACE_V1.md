## 策略规则（trend-v1）

- 默认只做多；可在创建回测/实例时开启趋势做空。
- 使用 UTC 已收盘完整日线 EMA20 判断方向，小时 EMA20/50 判断趋势。
- 小时收盘突破此前 20 根完整小时 K 线最高价/最低价，并符合上述方向时产生信号。
- 信号在下一分钟开盘按设定滑点模拟成交，不能在产生信号的小时内提前成交。
- 初始止损距离为 2 倍小时 ATR14；每小时收盘后更新移动止损，只收紧。
- 小时收盘反向穿越 EMA20 时，下一分钟开盘退出。没有马丁、补仓、固定获利后重开。
- 开仓名义价值限制在当时模拟权益以内；持有后名义价值/权益比会随行情变化，不承诺始终低于 1。
- 默认本金 10,000 USDT，单笔计划风险 0.5%，单边手续费 5 bps、滑点 3 bps，日内亏损限制 3%，最大回撤熔断 15%。这些是研究参数，不是交易所实时费率。
- 止损跳空按照更差的开盘价并加滑点成交。日内/最大回撤以分钟收盘权益检查，阈值不是实际最大亏损保证。
- 每个实例使用独立模拟资金，多个实例之间没有共享账户风险预算。

## 数据导入

单合约、升序连续 1 分钟 CSV/TSV，首行为列名：

```csv
timestamp,open,high,low,close,volume,funding_rate,mark_price
2026-01-01T00:00:00Z,90000,90100,89900,90050,100,0.0001,90048
2026-01-01T00:01:00Z,90050,90100,90000,90080,120,0,90078
```

时间支持带时区 ISO 时间或秒/毫秒/微秒 Unix 时间，必须对齐分钟；无时区日期不接受。
费率为小数，0.0001 表示 0.01%。结算所在分钟记录实际费率和结算标记价格，其他分钟费率明确填 0。
资金费按结算分钟开始前已持有的仓位计算：正费率多付空收。同分钟新开仓不追扣；这属于分钟回测约定，无法还原分钟内逐笔先后。
每分钟 mark_price 必填；非结算分钟的该字段不影响费用计算。

当前导入要求已合并的文件，**不直接支持把币安原始 K 线 ZIP 和独立资金费 CSV 分别上传后自动合并**。
导入至少 60 根，回测至少 22 天，前约 21 天用于预热，建议导入远长于预热期的数据。
模板只演示格式，不能直接用于回测。数据缺失、重复列、重复分钟、乱序和非法 OHLC 会拒绝，不自动补齐或默认为零。
零资金费必须由数据提供者确认，系统不能从全零文件判断是否漏合并了历史结算数据。
单文件上限 1 GB / 300 万行，12 个数据集/用户，50 次回测/用户。删除数据集会删除其回测结果。

## 模拟运行与恢复

浏览器只请求本站 `/api/strategy/*`；本站服务器请求币安公共接口。
行情图支持小时/日线，显示最新 180 根；最新图表 K 线可未收盘，策略不使用它产生信号。
服务器每 30 秒轮询已收盘分钟数据，模拟下一分钟开盘成交；并非逐笔撮合或可实现的实盘成交承诺。
资金费使用 `/fapi/v1/fundingRate` 实际结算记录，`premiumIndex.nextFundingTime` 用于核对是否漏结算，不使用预测费率代替实际结算。
到结算时间但实际记录未到、数据缺口、接口失败会暂停实例并显示原因；不会把失败请求当作零费用。
首次启动加载完成的小时/日线预热数据，从下一个完整小时开始观察，不补做过去信号。
关闭网页不影响服务端已启动模拟；服务器必须持续运行。
重启服务器会暂停实例并保留仓位；手动恢复最多允许 5 分钟缺口，超过需重置模拟账户。暂停不等于平仓。
每用户最多 5 个实例。真实自动交易需另行完成交易所精度/最小名义金额、实盘订单状态机、对账、断线保护和账户级风险预算。

## 结构与性能

- `lib/strategy/engine.js`：纯状态机，历史与实时模拟共享。
- `lib/strategy/worker.js`：流式 CSV 导入和 SQLite 迭代回测。
- `lib/strategy/service.js`：用户隔离、工作队列、持久化和币安行情轮询。
- `routes/strategy.js`：现有登录鉴权，按用户校验所有数据集/任务/实例的所有权。
- `components/strategy/`：懒加载页面、共用价格/权益 SVG 图表，鼠标显示日期和数值。
- 一次只运行一个 Worker，JS 堆上限 256 MB；排队有上限，不占用 API 主线程运行逐分钟回测。
- 页面可见时每 4 秒读轻量状态，不回传未显示的完整成交/曲线；回测结果点击后读取。行情接口缓存 30 秒。
- 每实例状态只保存最近 240 小时、120 日、1,000 笔交易、受限的权益曲线；总交易数/收益统计不随历史裁剪而减少。结果页显示最近 100 笔。
- 数据默认 `data/strategy/`，可用 `STRATEGY_DATA_DIR` 覆盖；已排除 Git 和部署数据覆盖。
- 本版状态 JSON 采用临时文件加替换方式保存，**只支持一个策略服务进程写入此目录**，不得多个 PM2 cluster 实例共享写入。后续多进程需迁移数据库任务锁与状态事务。
- 状态文件损坏时策略接口返回 503，禁止覆写损坏状态，虚拟币/雷达服务继续；需恢复备份后重启。

## 回测限制

未模拟交易所强平、盘口深度冲击、最小数量/价格步长及跨实例资金占用。
回撤来自分钟收盘权益，不等于分钟内最大浮亏。样本末尾未平仓按最后收盘强平并收费。
小时/日线用完整分钟聚合；不完整开头周期不产生信号。需用独立时期和不同行情验证策略，而不是只看单次收益。

## 同轮自审修复

- 雷达切换合约/周期时先清除旧曲线，市值请求增加序号保护，避免旧请求覆盖新合约；卸载后停止排队刷新。
- 已平仓详情保留历史已实现盈亏，不再被实时持仓列表中的缺失项覆盖为零；重新开仓则展示当前仓位。
- 页面加载调度器失败后允许重试，不永久缓存被拒绝的 Promise。
- 不完整小时不重复使用前一个小时的策略信号；实际资金费缺失暂停；异步模拟结果通过实例版本检查避免覆盖暂停/重置。
